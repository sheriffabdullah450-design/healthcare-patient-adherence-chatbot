
# Healthcare Patient Adherence Chatbot

## About
A Python application to manage medicine schedules and monitor adherence status.

## Features
- Add medicine schedules
- Mark medicine as Taken
- Delete schedules
- Patient-wise reports
- CSV report download
- Adherence percentage
- Charts and reminder alerts
- Healthcare assistant

## Technologies
- Python
- Streamlit
- SQLite
- Pandas
- Plotly

## Run the Project
Install dependencies:
pip install -r requirements.txt

Run the application:
python -m streamlit run app.py
